# Seshat

<img src="seshat.jpg" width="500" />

Image credit: [stablediffusionweb.com](https://stablediffusionweb.com/image/23350238-goddess-seshat-portrait-based-on-mythological-info)

Seshat is a distributed information retrieval system, that is built on top of a robust indexing layer powered by Lucene, and the storage is powered by [tatzelwurm](https://github.com/puntertram/tatzelwurm).
